Detailed Description

Event filter that gives any QLineEdit Esc / Ctrl+Z revert-to-focus-in behavior.

On FocusIn the current text is captured. When the user presses Escape or Ctrl+Z (while the text differs from the captured value), the text is restored and focus is cleared on the designated target widget via a deferred call.

Usage: new LineEditRevertHandler(lineEdit, clearFocusTarget);

The handler parents itself to lineEdit so it is destroyed automatically.
