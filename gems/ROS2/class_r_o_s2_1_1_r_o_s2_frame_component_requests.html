Global frame name in ros2 ecosystem with namespace. It is configurable through Settings Registry at /O3DE/ROS2/GlobalFrameName If not configured, it defaults to "odom". If empty, root frame is not published by the simulator. It is typically "odom", "map", "world", "myRobot/odom"
