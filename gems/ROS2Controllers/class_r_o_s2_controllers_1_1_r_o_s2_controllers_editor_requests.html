Detailed Description

Interface for creating ROS2 controller components. This interface provides methods to create various types of ROS2 controller components, such as wheel controllers, robot control, vehicle models, and joint controllers. It is intended to be used by external tools that create entities, e.g., when importing robots from SDF, URDF, or OpenUSD.
