Detailed Description

Staircase build parameters the Draw Shape tool reads from the component. Plain data snapshot exposed through EditorWhiteBoxComponentRequestBus::GetDrawStairInfo so callers fetch the whole group in one request. Defaults match an unset/unhandled component.
