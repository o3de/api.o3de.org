Detailed Description

Internal helpers backing the CSG integration layer (see WhiteBoxCsg.cpp). These convert between white box meshes and the engine-agnostic Csg::TriangleMesh, group/clean the coplanar regions a boolean leaves behind, and rebuild a white box mesh from a triangulated result. Declared here so they can be unit tested and so the implementation file stays focused on definitions.
