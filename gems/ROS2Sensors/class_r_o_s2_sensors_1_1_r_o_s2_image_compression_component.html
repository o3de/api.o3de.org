Detailed Description

Compresses camera frames and publishes them as sensor_msgs::msg::CompressedImage. Game counterpart of ROS2ImageCompressionEditorComponent, which builds it; it is not added by hand, so it creates its publisher only in a running simulation and never in the Editor.
