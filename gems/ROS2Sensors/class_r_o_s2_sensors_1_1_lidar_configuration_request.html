◆ SetConfiguration()

virtual void ROS2Sensors::LidarConfigurationRequest::SetConfiguration ( const LidarSensorConfiguration &  configuration)
pure virtual

Sets the configuration of the component. Each component should handle the configuration change without fully reinitializing the ROS2 publisher. This will allow to change the configuration of the component at runtime. Note: this method does not verify the configuration, so it is up to the caller to ensure that the configuration is valid.
